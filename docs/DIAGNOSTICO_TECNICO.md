# Cómo obtener el diagnóstico técnico

1. Despliega el ZIP completo de esta versión en el mismo sitio Netlify.
2. Abre la app y entra en **Ajustes**.
3. Baja hasta **Diagnóstico técnico**.
4. Pulsa **Guardar y sincronizar ahora** una sola vez.
5. Vuelve al panel y pulsa **Copiar diagnóstico**.
6. Pega aquí el texto copiado. No contiene cookies ni secretos de autenticación.

Los registros se guardan en el navegador del dispositivo, no en Netlify. Los errores de HTTP incluyen el endpoint y el código de estado. Los fallos del almacenamiento local incluyen el nombre de excepción cuando el navegador lo proporciona.
